# Enterprise Network Design and Implementation

Designed and configured a small enterprise network using Cisco Packet Tracer.

NETWORK COMPONENTS
- Cisco Routers
- Cisco Switches
- End Devices
- VLANs
  

TECHNOLOGIES AND PROTOCOLS
- IPv4
- Subnetting
- VLAN
- 802.1Q Trunking
- Inter-VLAN Routing
- DHCP
- Static Routing
- OSPF


DEPARTMENTS
- HR
- Finance
- IT
- Sales


SECURITY
- SSH for secure remote management
- Switch port security
- Extended ACL to restrict Finance-to-HR traffic

TROUBLESHOOTING
Performed troubleshooting for:
- Incorrect IP configuration
- Incorrect VLAN assignment
- Broken trunk
- OSPF routing problems


TOOLS
- Cisco Packet Tracer
- Wireshark
